# 数据字段提取任务

## 抽取的数据来源
pdf文件经过mineru解析后的md文档
该文档分布在： mineru-output目录下，每个目录对应一个pdf文档解析后的md文档。

## 抽取的目标要求

最终任务的规范和要求：参考[文档](赛题详细描述.md)

## 抽取的大概流程（思路）

[] 按照这个特点，抽取思路是这样：

1. 文档分类（招股说明书、提示性公告等）：信息一般都在招股说明书里面，分类结果为提示性公告可以直接跳过。

2. 文档切分：按照大章节切分（可以用规则，因为每个招股说明都有目录，目录给出了章节的标题和页码）。

3. 特定章节抽取特定字段（前期可以粗暴些，直接上大模型）

[] 抽取还有一个任务，就是把目录结构抽取出来，这个靠规则可以抽个八九成，

不过可以先规则，就按照他们给的文档枚举一些规则。

我们可以按照字段大类分一下，各自解析一些字段。比如，发行人信息、财务信息、风险信息等。

注意： 如果有更好的抽取思路，可以提出来，我会考虑一下。
